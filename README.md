# 教我说话 —— 设计说明

## 安装

1. 下载仓库代码，或直接用 `astrbot_plugin_speech_lessons` 目录打成 zip；
2. AstrBot 面板 → 插件 → 上传插件，选 zip，装完重启；
3. 在插件配置里把 `owner_ids` 填成你的 QQ 号；**留空则只认 AstrBot 管理员**（不会默认放行任何人）；
4. 私聊它说一句「你刚才那句不对，应该说……」试试。

## 解决什么问题

在群里它说胡话，你私聊告诉它"这句不对，应该说……"。这种话**进不了长期记忆**：
- 它是"行为规矩"，不是"发生过的事实"；
- 而且必须**跨会话生效**（私聊教的，群里要用），正好和记忆插件的隐私边界相反。

所以单独一个插件，规则和事实记忆分库存。

## 它怎么判断"你在教它"

三档，从省到贵：

| 档位 | 条件 | 动作 | 成本 |
|---|---|---|---|
| strong | 命中强信号（教/纠正/以后别/应该说/记住…） | 本地正则直接抽规则 | 0 |
| possible | 有弱信号（不对/语气/太生硬/你刚才…）且够长 | 调模型判定 + 提炼 | 1 次短调用 |
| chat | 其余（含纯寒暄） | 直接放过 | 0 |

强信号里抽不出来时，才降级给模型。

## 复习与衰减

- 正向反馈（"对/就是这样/乖"）：`reps+1`，间隔 1 → 3 → ×EF 天，权重 +0.25
- 负向反馈（"还是不对/又错了"）：间隔归零、EF −0.2、权重 −0.35，并给下一轮一句"先按主人意思改，别辩解"
- 只被注入、没有反馈：**只记一次使用，不推进间隔**（避免"注入即复习成功"的伪遗忘）
- 闲置衰减：每天 −`decay_per_day`，跌破 `archive_weight` 归档

## 注入位置

`req.system_prompt` 末尾，带标记 `<!--speech_lessons:rules-->`，
按权重排序、限条数（默认 8）与限字数（默认 700）。

## 数据

`data/plugin_data/astrbot_plugin_speech_lessons/lessons.db`（SQLite + WAL，单表 `lessons`）。

## 指令（仅主人）

```
/教 列表          看记住了哪些规矩
/教 删 3          删掉 id=3
/教 清            全部归档
/教 关 / 教 开    临时停用 / 恢复
/教 测试 <一句话>  诊断这句话会不会被当成教学
```

## 已知边界

- 只在私聊学，群里教不生效（按需求）；
- 模型判定失败一律"不学"，宁缺勿滥；
- 规则条数上限默认 300，防止越积越多互相打架。
